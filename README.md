One original one-line comedy joke, picked from 8 candidates by simulated head-to-head judging against the published judge brief (concrete scene, a turn in the last third, an unanswered question, economical at 98 characters). `main.py` writes it to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

The program writes the selected joke (98 characters, one line, UTF-8) to `/output/entry.txt`. It validates the gate itself first: 1–280 characters, not blank, a single line.
